# GrowthCognix brand system v1.0
- Mark: an open G whose arc releases a rising node: insight leaving the system as growth. Drawn on a 64-unit grid (build.py).
- Wordmark: "Growth" Instrument Sans 600 + "Cognix" 500 in primary colour, outlined to paths.
- Tagline: "Marketing that thinks. Growth you approve."
- Colours: Ink #0C1210, Paper #F5F4EF, Growth #0F7B5F (primary, light), Signal #C8F169 (primary, dark), Slate #5B635F, Mist #E4E3DC.
- Type (all free, OFL): Instrument Sans (UI), Instrument Serif Italic (one accent phrase per page), JetBrains Mono (numbers, code).
- Rules against "AI look": no purple/blue gradients, no glows, no glassmorphism, no sparkle icons, no stock robots; hairline borders, warm paper neutrals, real copy.
- tokens.css: CSS variables for light/dark themes.
Regenerate: python3 build.py && python3 sheet.py
